# TasteBridge tool observations

Prepared from development evidence for entrant review. Codex and Claude assisted implementation, interface work and video preparation.

- **Qloo Taste AI:** Actual local search enabled movie/artist confirmation; insights supplied per-member candidates and returned order for rank comparison. Metadata/explanations may be missing and posters can fail. Rate limits need visible recovery, server-only keys, bounded retry/cache and exact entity validation. Captured returned data is excluded from public source. No universal quality claim is made.
- **Local Codex / gpt-6-luna:** Structured planning used eligible ChatGPT login and bounded tools. Live retrieval/refinement was observed; latency, nondeterministic planning and account allowance remain limits. Local requests allow 90 seconds and subscription authentication stays local. Hosted Groq allows 20 seconds, a 6,000-byte complete JSON request and 1,024 completion tokens, with no automatic model retry.
- **React/TypeScript/Vite:** The cinematic interface shows explicit confirmation/rank evidence and retains valid results after failed updates. Current frontend checks passed 78 tests in 13 files plus typecheck/build; fixtures do not prove public connectivity or visual quality.
- **Python/FastAPI/Pydantic/HTTPX/SQLite:** Server validation separates permission from planner output and version-checks publication. The 2026-10-09 full offline backend passed 178 tests / 1 live test deselected, including storage network-deadline, async availability and lost-commit-response checks. Remote HTTPX storage uses official Turso `/v2/pipeline` with deadlines and synchronous calls in a thread pool. Real hosted integration remains unverified.
- **Fontsource / Manrope / DM Serif Display:** Locally bundled typography avoids a runtime font CDN; licenses ship with the build.
- **Groq Free / Render Free / Turso Free:** Selected targets; accounts have not yet been set up/live tested. Remote daily claims default to 100 model / 500 Qloo physical requests per UTC day, including failed requests/retries; actual Free quotas may throttle sooner. Live planning, remote behavior, capacity and external workflow are unverified. No hands-on success or paid fallback is claimed.
