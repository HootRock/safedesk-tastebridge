# TasteBridge tool observations

Prepared from development evidence for entrant review, as of **2026-10-09**. Codex and Claude assisted implementation, interface work and video preparation. The [public application](https://tastebridge-hackathon.wtr1274970944.workers.dev/tastebridge) completed actual two-member search, an initial recommendation and all three permitted successful exact seen-film updates.

- **Qloo Taste AI:** `/search` resolves explicitly confirmed movie/artist preferences; `/v2/insights` supplies up to twenty candidates per member and their returned order. The interface displays genuine returned metadata and rank evidence. Missing ranks are missing evidence, not dislike. Metadata/explanations may be absent and poster hosts may fail. A finite one-MiB response guard, server-only key, bounded retry and private cache constrain integration. Only seven typed/bounded card fields are retained; unused rich properties are discarded after complete literal/decoded secret-reflection checks. Captured returned data is excluded from public source. No universal recommendation-quality claim is made.
- **Cloudflare Workers / native Workers AI / D1:** The selected public runtime uses Workers Free, Static Assets, native `AI` and durable `DB` bindings with the fixed `@cf/meta/llama-3.3-70b-instruct-fp8-fast` planner. Migration and the encrypted Production Qloo runtime secret are configured. D1 stores versioned groups/runs, physical-request claims, shared leases and private cache. Native model requests allow 20 seconds, a complete 6,000-byte JSON input and 1,024 output tokens, with no automatic model retry. Four model attempts/eight tools are allowed per workflow. Parameterless retrieval/ranking stages constrain generated arguments to `{}` and one offered call; the server validates all output independently. Earlier rejected feedback attempts preserved the prior shortlist, and the current release successfully retried and completed all three exact exclusions.
- **Free-account operation:** D1 enforces 100 model / 500 Qloo physical requests per UTC day, including failures/retries. Shared leases allow two workflows and two Qloo calls; sessions/results expire after 24 hours. These limits differ from provider Free quotas. The current active-version sample reported six invocations, zero errors, a 5 ms CPU summary and a recent CPU p99/p999 bucket of 142 ms, with no recorded CPU-limit rejection. It does not establish that complete requests stay within the Workers Free CPU allowance, capacity under concurrency or judging uptime. No payment card, additional spending, paid fallback or upgrade is authorized.
- **React/TypeScript/Vite:** The cinematic interface shows explicit favorite confirmation, returned poster/film details and per-person rank evidence. It retains valid results after failed updates. The frontend baseline passed 84 tests in thirteen files, typecheck and build; fixture checks do not prove visual quality or every live reliability case.
- **Python/FastAPI/Pydantic/HTTPX/SQLite and local Codex:** The original local application remains available independently. Local structured planning uses official Codex CLI, `gpt-6-luna` and eligible ChatGPT allowance, with a 90-second request deadline; subscription authentication stays local. The offline backend passed 216 tests / one live test deselected. Earlier Python Cloudflare REST/Groq/Turso alternatives are preserved but are not the deployed native Worker runtime. Render's card request caused that route to be rejected for this release.
- **Fontsource / Manrope / DM Serif Display:** Bundled typography avoids a runtime font CDN; font licenses ship with the build.
- **Validation and packaging:** Current Worker code passed 146 tests in eight files, typecheck and dry packaging. [Public CI](https://github.com/HootRock/safedesk-tastebridge/actions/runs/37921112133) passed all three jobs. A fresh independent public-source copy matched all 152 expected files by SHA-256. Tests cover strict native response validation, deadlines, physical claims, shared leases, D1 simulation and feedback rollback. A fully wired synthetic four-member/retry workflow used 41 D1 statements including run/group reads. Real four-member, session isolation and concurrency/capacity remain broader live checks; offline evidence is not a live measurement.
